# ゆるAWS勉強会 プロジェクト概要

## 🎯 勉強会の目的

AWSのサーバーレス技術とCI/CDを、実践的なプロジェクト開発を通じて学ぶコミュニティです。

### 解決したい課題
- **理論だけでは身につかない**: 本や記事を読んでも、実際に手を動かさないと理解が浅い
- **孤独な学習**: 一人だと挫折しやすい、質問できる人がいない
- **実務経験の不足**: ポートフォリオになる実績が欲しい

### この勉強会の提供価値
1. **実践的な学習**: Hello Worldから始めて、実際にデプロイできるアプリを作る
2. **コミュニティサポート**: つまずいたらすぐ質問できる環境
3. **ポートフォリオ作成**: 各自がGitHub上に公開できる成果物を作る
4. **チーム開発経験**: 最終的には複数人での協働開発も体験

---

## 🛠️ 学習する技術スタック

### AWSサービス
- **Lambda**: サーバーレス関数
- **API Gateway**: REST API提供
- **DynamoDB**: NoSQLデータベース
- **S3 + CloudFront**: 静的サイトホスティング
- **Cognito**: ユーザー認証
- **Bedrock**: AIサービス（オプション）

### 開発ツール
- **AWS SAM**: サーバーレスアプリケーション開発フレームワーク
- **GitHub Actions**: CI/CD自動化
- **Docker**: コンテナ化（ローカル開発）

### プログラミング
- **Python**: Lambda関数開発
- **JavaScript/React**: フロントエンド（オプション）

## 📅 学習の進め方（3段階）

    AIが勝手に生成した学習の進め方なので、話半分で読んでください。詳細についてはメンバーで話し合って決めるので、以下は更新対象。

<details><summary>AI作の学習プラン（展開可能）</summary>

### Stage 1: 基本構成
**目標**: ログインできて、APIが叩ける最小システム

- AWS/GitHubアカウント作成
- ローカル開発環境構築（WSL/Docker/SAM CLI）
- SAM Hello World デプロイ
- Cognito認証の実装

**完了条件**: 
- ユーザーがログインできる
- API Gatewayを通じてLambda関数を実行できる

---

### Stage 2: データ駆動
**目標**: データを保存・取得できるアプリケーション

- DynamoDB設計・実装
- CRUD API作成
- 定期実行（EventBridge）
- 簡単なフロントエンド

**完了条件**:
- データがDynamoDBに保存される
- APIでデータの読み書きができる
- ブラウザでデータ一覧が見える

---

### Stage 3: 高度な機能
**目標**: 非同期処理、AI統合、自動デプロイ

- SQSキューでの非同期処理
- Bedrockでの生成AI活用（オプション）
- GitHub Actionsで自動デプロイ
- 監視・ログ設定

**完了条件**:
- 非同期処理が動作する
- mainブランチへのpushで自動デプロイされる
- CloudWatchでログが確認できる

</details>

## 🎓 学習スタイル

### 個人ペースでOK
- 週1時間でも、毎日3時間でも、自分のペースで進める
- 強制参加のイベントはなし（もくもく会は任意参加）

### 質問大歓迎
- 初歩的な質問も遠慮なく
- わからないことは早めに聞く方が効率的

### 成果を共有
- 小さな成功でも報告し合う
- お互いのモチベーションになる

## 🚀 最終的なゴール
